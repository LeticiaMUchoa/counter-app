# 🚉 Counter App

Um contador simples de pessoas que sobem no trem, metrô ou plataforma — desenvolvido como parte das minhas atividades no curso da **Scrimba** para praticar **JavaScript**, **HTML** e **CSS**.

O objetivo do projeto é aprender manipulação de elementos do DOM, eventos e lógica básica em JavaScript.

---

## 🖼️ Demonstração

🔗 [Acesse o projeto no Netlify](https://platform-counter.netlify.app)

---

## 💡 Funcionalidades

- Exibe o número atual de pessoas que entraram.
- Permite **incrementar** o contador com o botão `INCREMENT`.
- Permite **salvar** os valores anteriores clicando em `SAVE`, mostrando o histórico de entradas.
- Reinicia o contador após cada salvamento.
- Possui um botão `RESET` que zera o contador e apaga o histórico de entradas.

---

## 🧠 Tecnologias utilizadas

- **HTML5** — estrutura da página  
- **CSS3** — estilização e responsividade  
- **JavaScript** — manipulação de DOM e lógica do contador  
- **Google Fonts** — tipografia “Playfair Display”
